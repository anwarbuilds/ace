# ACE Learning Log

## Project Setup

### Virtual environments

ACE uses Python 3.12.12 selected with pyenv and a project-local `.venv`.

- `pyenv` selects the Python version.
- `.venv` isolates ACE's Python packages.
- `.venv` is not committed to Git.

### Git

Git provides local version history for ACE.
GitHub stores the remote copy of that repository.
