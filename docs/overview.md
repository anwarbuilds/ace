# ACE platform overview

The current product overview, architecture, local setup and feature summary are
in the [README](../README.md). ACE is the Wine and Rose web platform on `main`,
with Next.js, FastAPI, PostgreSQL, independent discovery scheduling, Gmail Inbox
Intelligence and a paired Chrome extension.

Start operational work with the [current handoff](HANDOFF.md), the complete
[global continuity](../ACE_NEXT_KNOWLEDGE.md) and the relevant
[knowledge topic](knowledge/README.md). Production release instructions are in
the [operations runbook](../deploy/oracle/README.md). Historical migration and
legacy-system instructions are archived and must not be replayed as setup.
