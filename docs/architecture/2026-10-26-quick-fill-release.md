## What shipped

The shared company identity now displays the same authentic icon on lists and
inside details. FedEx Freight, General Motors and the other reviewed additions
are included. Future employers use the owner-only automatic logo route with
verified source identity, bounded public fetching, private cache and a visible
initials fallback. Actual images from every external site cannot be guaranteed.
See `2026-10-26-company-identity.md` for the full logo file list and evidence.

The extension has one full-width **Fill all known answers** action, a shorter
question editor, an optional collapsed question chooser and **Fill answer**.
One verified routine answer immediately fills equivalent empty prompts. Private
saving runs separately, so a save failure does not reopen a completed field.
There is no separate remember checkbox or required Memory screen. Undo is on
the compact card. Existing private answers, optional correction/delete controls,
preferences, control adapters, full-viewport movement, minimize and themes remain.
Each repeated control has its own completion identity. Dates/current-job choices
use their matched history entry and cannot become a global From/To answer.
Protected questions and motivation exclusions remain; ACE never submits or marks
an application Applied after filling.

The installed unpacked extension still requires Chrome **Reload** and a refresh
of employer tabs. Server deployment cannot replace scripts already injected into
an open browser tab. No Chrome Web Store publication occurred.

the standard prepare script, but no migration container was run. No scheduler
