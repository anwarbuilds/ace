Before changing this repository, read `ACE_NEXT_KNOWLEDGE.md` completely. It is
the cross-session continuity record for ACE Next, the legacy comparison system,
production verification, and current extension work. Then read
`docs/HANDOFF.md` and the relevant file in `docs/knowledge/`. Inspect the
working tree and branch history before editing because another agent may have
advanced the tracked remote branch.

Use the final ACE Focus Mode V5.1 package under `design/ace-focus-v5.1/` for
extension work, including its employer-motivation exception. Use the approved
Wine and Rose V2 package for the website. Preserve the existing extension,
backend, data, auth, discovery and application tracking.

Keep personal data, real answers, screenshots and credentials out of this
public repository. Do not claim a local test is production verification.
Deployment, extension publication, migration, scheduler changes and destructive
data operations require the owner's explicit approval for that operation.
